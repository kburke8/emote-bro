    Game Summary

    01›

    EmoteBros is a multiplayer lobby game where players collect little characters called EmoteBros, place them in their base, earn money over time, buy pets and upgrades, defend their base, and try to steal valuable EmoteBros from other players.

    There is no final "win" condition. The goal is to keep getting richer, collecting better EmoteBros, evolving them, buying better pets and mounts, unlocking VIP areas, and protecting your base from other players.

    The game is meant to feel like a fun Roblox-style tycoon/collector/stealing game.

    🔁

    Core Game Loop

    Built02›

    The basic loop:

    The continuous loop — there's no end state, just bigger numbers.
    1. Player joins a lobby.
    2. Player is assigned one of four bases.
    3. EmoteBros spawn on a blue/purple carpet path.
    4. Player spends coins to buy EmoteBros.
    5. Bought EmoteBros travel to the player's base.
    6. Once inside the base, EmoteBros generate money over time.
    7. Player steps on their money slab to collect earned money.
    8. Player uses money to buy: more EmoteBros, pets, base defenses, guard suits, lock upgrades, lucky blocks, evolutions.
    9. Other players can try to steal EmoteBros from bases.
    10. Player defends their base using locks, guards, weapons, teleport items, and upgrades.
    11. Hourly events, daily spin rewards, VIP zones, and mounts add extra goals.

    Map Layout

    Built04›
    Rough map layout — carpet on top, hub in the middle, four player bases below, VIP off to the side.

    Main Spawn Area

    Where players appear when they join. Includes the instructions board, daily spin wheel, shop, pet shop, lucky block shop, mount shop, VIP entrance, and event countdown board.

    EmoteBro Carpet Path

    A blue/purple carpet where EmoteBros appear and move.

    • EmoteBros spawn at the start of the carpet.
    • They move along the carpet toward the finish.
    • Players can buy them while moving.
    • If an EmoteBro reaches the finish without being bought, it disappears.
    • A lever can change which direction the EmoteBros are moving.

    Four Bases

    Each lobby has four bases around the map. Each base includes 12 carpet spheres/slots for EmoteBros, a money collection slab, a lock slab, a base entrance, guard slots, owner-only messages, and a base teleport destination.

    Pet Store

    Players buy pets here. Pets increase the amount of money earned.

    VIP Area

    Only VIP players can enter. Has a special carpet, better rewards, double-quality stuff, better EmoteBros, better lucky blocks, better items.

    ✨

    Everything in the VIP area should be roughly 2× as good as normal.

    EmoteBros

    Built05›

    EmoteBros are collectible characters that players buy, place in their base, and use to earn money. They are the main collectible and money-making system.

    Spawning

    EmoteBros spawn on the main carpet. Each has: name, rarity, cost, money/sec, appearance, evolution level, sometimes special traits.

    Example EmoteBros

    Name Rarity Cost Money/sec
    Basic BroCommon251
    Silly BroCommon753
    Cool BroUncommon25010
    Mega BroRare1,00040
    Secret BroSecret???Very high
    Evolved BroEvolvedEvolution onlyHigher than original

    Buying an EmoteBro

    • If they have enough money: spend it, EmoteBro becomes owned, walks/slides to base, takes next available slot.
    • If no space: show "Your base is full!"
    • If not enough money: show "Not enough coins!"

    Base Capacity

    Each base has 12 EmoteBro slots. If all 12 are full, the player must sell one, evolve/combine, upgrade storage later, or replace one. For v1: 12 max, can sell/remove.

    Money Generation

    Each EmoteBro generates money over time. Money is not instantly added to the wallet — it builds up in the base bank. The player must step on the money slab to collect.

    "Collect: 1,250 coins"

    Evolving EmoteBros

    3 of the same EmoteBro can evolve into 1 stronger version. Evolution costs coins or special currency.

    InputCostResult
    3 Basic Bros100 coinsSuper Basic Bro
    3 Cool Bros1,000 coinsMega Cool Bro
    3 Mega BrosSpecial currencyUltra Mega Bro

    Event EmoteBros

    Some events announce special EmoteBros — Secret Egg, Mega EmoteBro, ready-to-evolve EmoteBro. These appear on the carpet during events.

    Bases

    Built07›

    Base Parts

    • 12 EmoteBro slots
    • Money collection slab
    • Lock slab
    • Entrance
    • Owner label
    • Defense item area
    • Guard positions

    Money Slab

    • Only the base owner can collect.
    • When the owner steps on it: add stored base money to wallet, reset to 0, play coin sound.

    Lock Slab

    When the owner steps on the lock slab:

    • Base locks for 2 minutes.
    • Other players can't enter.
    • Timer appears above the base / near the door.
    • When the timer ends, the base unlocks.

    Owner-Only Messages

    When the base becomes unlocked, only the owner sees "Your base is unlocked!" — this message is private. Other players do not get a warning.

    Stealing System

    Built08›

    Players can try to steal EmoteBros from other players' bases.

    Stealing sequence — fail at any step and the EmoteBro is recovered.

    Basic Stealing

    A player can steal an EmoteBro if: the target base is unlocked, the player can reach the EmoteBro, the EmoteBro is not protected by a guard, the thief is not stunned or blocked.

    1. Player interacts with an enemy EmoteBro.
    2. EmoteBro becomes "carried" or follows the thief.
    3. The thief must get it back to their own base.
    4. If successful, the EmoteBro is added to the thief's base.
    5. If the thief gets stunned, teleported, or knocked away, the steal can fail.

    Stealing Risk

    Stealing should be risky because defenders can use: base locks, guards, guard bows, teleport guards, maces, knockback items, base teleport items, lock upgrades.

    ⚠️

    A stolen EmoteBro is not fully stolen until it reaches the thief's base. Until then, it can be recovered.

    🔐

    Base Lock Upgrades

    Built09›

    Normal Lock

    Blocks other players from entering for 2 minutes.

    Teleport Lock Upgrade

    An upgraded lock looks the same as a normal lock, but has a hidden effect — if another player touches it, they're teleported back to their own base. Looks normal, so it's hard to tell if it's upgraded. A sneaky trap.

    Possible Lock Upgrade Levels

    LevelEffectCost
    1Locks base for 2 minutesFree / default
    2Slightly shorter cooldownCoins
    3Teleports intruders to their baseCoins + special currency
    4Longer lock durationSpecial currency
    5Hidden trap lockVIP / special currency

    For v1: normal lock + teleport lock.

    🛡️

    Guard System

    Built10›

    Players can buy a guard suit from the shop and put it on an EmoteBro — that EmoteBro becomes a guard.

    Guard Rules

    • Protects the base
    • Has a fixed vision range
    • Detects intruders inside that range
    • Attacks or uses an item if an intruder gets close
    • Does not protect the entire base by itself

    Guard Range

    Use a circle around the guard. Example range: 15 studs / tiles / units. If an enemy enters the range, the guard reacts.

    Guard Types

    👮Basic GuardRuns at enemies, knocks back, brief stun.
    🌀Teleport GuardTeleports enemy randomly or to their own base.
    🏹Bow GuardRanged attack, 2-sec stun.

    Guard Items

    ItemEffect
    MaceKnocks enemy away and stuns 4–5 seconds
    Teleport WandTeleports enemy to random location
    Base TeleporterTeleports enemy to their own base
    BowStuns enemy from range for 2 seconds

    Guard Balance

    Guards should not be unbeatable. Limitations: fixed vision range, attack cooldown, only protects part of the base, can be distracted/avoided, strong guards cost more.

    ⚔️

    Player Defense Items

    Built11›

    Mace

    Used when someone is outside the base waiting for the lock to expire.

    • Knock target far away
    • Stun target for 4–5 seconds
    • Cooldown after use

    Suggested values: medium knockback, 4-sec stun, 15-sec cooldown.

    Teleport-to-Base Item

    Lets the player teleport back to their base. Useful when their base is unlocked, they see the private message, and they need to stop a thief.

    • Player activates item.
    • Player teleports to their base.
    • Item has cooldown or limited uses.

    v1: 60-sec cooldown, cannot use while stunned.

    Events

    Built17›

    Events happen every hour by default.

    Event Timer

    "Next Event: 42:15"

    When the timer reaches 0, an event starts.

    Event Types

    🥚Secret EggHatch for a rare chance
    💪Mega EmoteBroPlayers race for it
    ⚗️Ready-to-EvolvePre-evolved special
    🌧️Lucky Block StormExtra blocks appear
    👑VIP EventBonus VIP rewards

    Speeding Up Events

    Players can spend special currency to make the next event happen sooner. Important: spending currency only speeds up the next event — it does not permanently speed up all future events.

    🎭

    Hidden Good EmoteBro Twist: when a player speeds up an event, they may get a special EmoteBro that looks bad to everyone else. To others, it looks bad / weak / not worth stealing. Once it reaches the owner's base, it reveals its true form — and it's actually very, very good. A secret treasure mechanic.

    • EmoteBros may start moving along a different path
    • Can affect which players reach them first
    • Changes strategy

    Cooldown

    Lever should have a cooldown — example 30 seconds. Only one lever pull every 30 seconds globally.

    "The EmoteBro path has changed!"

    Important Balance Rules

    23›

    The game should feel fun, not unfair.

    Stealing Balance

    🛡️ Defender advantages

    • Lock
    • Private unlock message
    • Teleport-to-base item
    • Guards
    • Mace
    • Teleport lock upgrade

    🦹 Thief advantages

    • Can wait for lock to expire
    • Can sneak around guard range
    • Can use speed mount
    • Can steal valuable EmoteBros

    Money Balance — Early Game Pacing

    MilestoneTarget Time
    First EmoteBroWithin 10 seconds
    First pet2–3 minutes
    First lucky block5 minutes
    First guard10 minutes
    First evolution15–20 minutes
    VIP / mount goalsLater

    Base Capacity Balance

    12 slots is good because players have to make choices. They should ask: Do I keep this EmoteBro? Evolve? Replace? Make it a guard? Risk stealing a better one?
